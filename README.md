## Program Description

This program is a unit converter built using JavaScript and Tailwind CSS. It allows users to switch between weight, distance, and temperature conversions and apply the correct formula for each category. The input section accepts one value or several values separated by commas, and the interface updates the labels and direction as the user changes the converter type or reverses the calculation. The program processes the entered data by validating the input, selecting the correct conversion rule, and formatting the final result to two decimal places. The output is shown in the result panel and updates immediately when the user clicks the convert button or swaps the conversion direction.

## Inputs, Processing, and Outputs

- Inputs: numeric values entered by the user, with optional comma-separated values for multiple conversions.
- Processing: the program validates the input, chooses the correct unit formula, and converts the value to the selected target unit.
- Outputs: the converted value is displayed in the result panel with two decimal places and the correct unit label.
